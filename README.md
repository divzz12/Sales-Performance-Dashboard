# 📊 Sales Performance Dashboard

A comprehensive data analytics solution using **Power BI**, **SQL**, and **Excel** to resolve fragmented reporting, identify regional revenue bottlenecks, and drive quantifiable business growth.

---

## 📌 Business Problem

Regional sales leadership struggled to identify revenue bottlenecks across multiple retail branches due to fragmented quarterly CSV reports[cite: 1]. This created data silos and limited executive visibility into regional performance and product profitability[cite: 1].

---

## 🛠️ Tech Stack

* **Power BI**: Star-schema data modeling, dynamic DAX measures, and interactive reporting[cite: 1]
* **SQL**: Data extraction, transformation, and querying of transactional datasets[cite: 1]
* **Excel**: Initial data exploration, validation, and baseline analysis[cite: 1]

---

## ⚙️ Analysis & Methodology

1. **Data Extraction**: Extracted raw transactional data across retail branches using structured SQL queries[cite: 1].
2. **Data Modeling**: Engineered a star-schema data model in Power BI for clean data governance and fast querying[cite: 1].
3. **DAX Engineering**: Created custom DAX measures to enable dynamic Month-over-Month (MoM) performance tracking[cite: 1].
